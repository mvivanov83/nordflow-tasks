# NordFlow Tasks

Внутренний веб-трекер проектов и задач: Kanban-доска с drag & drop, роли (администратор, руководитель проекта, сотрудник), уведомления в приложении, комментарии, история изменений, вложения и адаптивный интерфейс.

## Быстрый запуск

Требуется **Node.js 24+**.

```bash
npm install
npm start
```

`npm start` собирает клиент (`vite build`) и запускает Express на `http://localhost:3000` (порт можно переопределить переменной `PORT`). При первом запуске автоматически создаётся схема БД и загружаются демо-данные.

Демо-данные можно пересоздать в любой момент:

```bash
npm run seed
```

### Режим разработки

```bash
npm run dev
```

Vite поднимает клиент с горячей перезагрузкой и проксирует `/api` на Express.

## Возможности

- **Kanban-доска** с колонками «Бэклог», «Запланировано», «В работе», «На проверке», «Выполнено» и drag & drop между ними.
- **Роли и права**: администратор управляет пользователями и всеми проектами; руководитель — своими проектами, участниками и задачами; сотрудник видит доступные проекты, меняет статус назначенных ему задач и создаёт задачи там, где это разрешено.
- **Задачи**: приоритет, срок, исполнитель, теги, описание, чек-лист, вложения, комментарии, история изменений.
- **Уведомления в приложении**: назначение, смена статуса и срока, новые комментарии, приближение дедлайна и просрочка.
- **Дашборд**: личная статистика, ближайшие дедлайны, лента обновлений, сводка руководителя по команде.
- **Поиск** по задачам, проектам и сотрудникам (`Ctrl/⌘ + K`).
- **Профиль**: имя, должность, аватар, смена пароля, светлая/тёмная тема.
- **Адаптивность**: мобильная навигация, горизонтальная прокрутка доски, выдвижная карточка задачи.
- SPA-роутинг с Express-fallback, JWT-аутентификация, пароли хранятся в bcrypt-хешах.

## Стек

- **Backend**: Node.js 24, Express 4, встроенный `node:sqlite` (без нативных зависимостей) или PostgreSQL через `pg`, JWT, bcryptjs, multer.
- **Frontend**: React 19, Vite 7, React Router 7, собственный CSS (светлая и тёмная темы).
- **Один сервис**: Express раздаёт собранный `dist` и API, поэтому для деплоя достаточно одного контейнера.

## Переменные окружения

Скопируйте `.env.example` в `.env` или задайте переменные в панели хостинга.

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт HTTP-сервера (по умолчанию `3000`). |
| `JWT_SECRET` | Секрет подписи токенов. **Обязательно задайте в продакшене.** |
| `DATABASE_URL` | Строка подключения PostgreSQL. Если не задана — используется SQLite. |
| `DATABASE_SSL` | `true`, если PostgreSQL требует SSL. |
| `DATABASE_FILE` | Путь к файлу SQLite (по умолчанию `data/nordflow.db`). |
| `UPLOADS_DIR` | Каталог аватаров и вложений (по умолчанию `uploads/`). |

## Деплой на Railway (один сервис)

В репозитории уже есть `railway.json`:

- build: `npm install && npm run build`
- start: `npm run serve`
- healthcheck: `/api/health`

Порядок:

1. Создайте проект Railway и подключите репозиторий.
2. Добавьте переменную `JWT_SECRET` со случайным длинным значением.
3. Для постоянного хранения данных выберите один из вариантов:
   - **PostgreSQL**: добавьте базу Railway и переменную `DATABASE_URL` (при необходимости `DATABASE_SSL=true`). Схема создастся автоматически.
   - **SQLite**: создайте Volume с Mount path `/app/data` и задайте переменные:
     - `DATABASE_FILE=/app/data/nordflow.db`
     - `UPLOADS_DIR=/app/data/uploads`
4. Задайте публичный домен в разделе Networking.

При первом запуске на пустой базе автоматически создаются схема, 8 демо-пользователей, 3 проекта и 33 задачи. Повторный запуск сид не дублирует: данные создаются только если таблица `users` пустая.

Без Volume и без PostgreSQL данные (SQLite-база и загруженные файлы) будут теряться при пересоздании контейнера.

## Структура проекта

```
client/            React-приложение (страницы, компоненты, стили)
server/
  index.js         Express: API, статика, SPA-fallback
  db.js            Адаптер SQLite/PostgreSQL
  schema.js        Схема БД
  seed.js          Демо-данные
  auth.js          JWT и проверка прав
  access.js        Правила доступа к проектам и задачам
  notify.js        Уведомления и проверка дедлайнов
  routes/          REST API
data/              Файл SQLite (создаётся автоматически)
uploads/           Аватары и вложения
info/tz.md         Техническое задание
```

## Полезные команды

```bash
npm start        # сборка + запуск production-сервера
npm run serve    # запуск без пересборки
npm run build    # только сборка клиента
npm run dev      # разработка (API + Vite)
npm run seed     # пересоздать демо-данные
```

Проверка работоспособности: `GET /api/health`.
